# Study Counter

## Запуск

Открыть проект в Android Studio. Установить JDK 17 и Android SDK 35. После синхронизации выбрать телефон или эмулятор с Android 7.0+ и нажать **Run**.

## Сборка

Windows:
```powershell
.\gradlew.bat assembleDebug
```

Linux / macOS:
```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
