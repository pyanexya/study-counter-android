# REST API и Postman

```bash
npm ci
node server.cjs
```

Откройте http://localhost:3000. Форма отправляет настоящие GET и POST к Express. После перезапуска список очищается. Сервер слушает только локальный интерфейс.

В Postman импортируйте `users.postman_collection.json`. Установите `baseUrl` в `http://localhost:3000`. Запускайте коллекцию на свежем сервере: первый тест ожидает пустой массив.

Автоматическая проверка той же коллекции через Newman:

```bash
node run-tests.cjs
```

Скрипт сам запускает отдельный сервер на порту 3107. Проверяет 5 запросов и 10 утверждений. Результаты сохраняет в test-results.json. Это тесты API; вход и JWT в данный сервер не добавлены.
